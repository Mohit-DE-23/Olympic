# 🏅 Olympics Data Analysis

## 📌 Project Overview

This project analyzes the **Olympic dataset** using Python to uncover meaningful insights about athletes, countries, sports, and medal distributions. The analysis includes data cleaning, preprocessing, exploratory data analysis (EDA), and visualizations to understand the performance of athletes and participating nations.

The project focuses on the **Summer Olympics** and demonstrates practical data analysis skills using popular Python libraries.

---

## 📂 Dataset

The project uses the following datasets:

* **athlete_events.csv** – Contains athlete information, event details, medals, age, height, weight, and participation history.
* **noc_regions.csv** – Maps National Olympic Committee (NOC) codes to country/region names.

---

## 🎯 Project Objectives

* Clean and preprocess Olympic data.
* Analyze athlete participation.
* Explore medal distribution across countries.
* Identify top-performing nations.
* Analyze gender participation.
* Study trends in age, height, and weight of athletes.
* Visualize Olympic statistics using charts.
